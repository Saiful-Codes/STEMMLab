# STEMM Lab Project Context

STEMM Lab is a React Native + Expo mobile app for upper primary and lower high school students.

The app turns real-world STEMM activities into game-based learning challenges.

Core startup flow:
- Enter team name
- Enter first names of team members
- Enter grade/year level
- App assigns a team discriminator

Core features:
- Activity catalogue
- Activity instructions
- Record attempts
- Upload media/video
- Use camera, sensors, GPS, timers, and analytics where suitable
- Ratings and comments
- Leaderboard
- Team profile and attempt history
- Light/dark theme
- Accessibility for poor eyesight

Main activities:
1. Parachute Drop Challenge
2. Sound Pollution Hunter
3. Hand Fan Challenge
4. Earthquake-Resistant Structure
5. Human Performance Lab
6. Reaction Board Challenge
7. Breathing Pace Trainer

Tech stack:
- React Native
- Expo
- TypeScript
- Local storage first
- Clean beginner-friendly code
- Modular folder structure
- Mobile-first UI

Development rule:
Build step by step. Do not generate the entire app at once. Always explain what changed.
